상태 흐름

  1. 답장 전 — 카톡 내용만 붙여넣은 상태 (현장에서 바빠도 10초면 끝)
  2. 작성 중 — 품목·사진·수량 확인 중
  3. 발행 — 방문견적 화면에서 발행 (/q/ 링크). 발행내역(코드·금액·날짜)은 현장관리 앱의 이 요청에 남음. 고쳐서 다시 발행하면 내역이 한 줄 더 쌓임
  4. 확정 → 현장 등록 또는 안 됨 (사유 한 줄)

가정 (확인 필요)

  • ‘기존 시공사진’ = 필름현장관리자 앱에 품목별로 올라간 작업사진(시공 전/후). 방문견적 저장함 사진은 폰 안에만 있어서 제외.
  • 금액 = 방문견적(quote_pro)의 품목 단가·난이도·평형 계산을 그대로 씀. 정산견적(품수 기반)은 참고만.
