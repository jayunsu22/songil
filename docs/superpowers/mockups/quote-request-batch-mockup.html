③ 겹쳐서 견적 항목위치+품목이 같은 사진과 글 줄은 한 항목으로 합침(중복 없음). 글만 있는 항목은 시공사진 DB에서 고르기, 사진만 있는 항목은 수량 1로 자동 추가. 빨간 카드가 남아 있으면 발행 전에 알려줌

합치는 규칙

  • 사진+글: 위치·품목이 같으면 한 항목. 수량은 글의 숫자(사진 장수가 아님).
  • 글만: 사진 없음 → 시공사진 DB(필름현장관리자 작업사진, 품목명으로 거름)에서 골라 견적서에 같이 보여줌.
  • 사진만: 글에 없던 품목 → 수량 1로 추가하고 ‘글에 없음’ 표시 (카톡에서 사진으로만 보낸 경우).
  • 순서 자유: 사진만, 글만, 둘 다 — 어느 탭부터 해도 ③에서 합쳐짐.
