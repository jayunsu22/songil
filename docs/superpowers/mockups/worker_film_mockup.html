품목마다 자재 칸에서 고른 필름 번호가 기사 앱에 그대로 나갑니다. 필름이 하나뿐인 현장은 손댈 게 없어요.

③견적에서 안 골랐을 때 — 위치 글자로 자동 짝

현장관리 앱 › 필름·부자재시공위치 | 필름번호

거실 화장실문px451
방3문+틀 ← "방3 문틀" → ps170
거실화장실문 ← "거실 화장실문" → px451 (자동)
현관문 ← 맞는 줄 없음 → 비워 둠

띄어쓰기·'+'는 무시하고 방3·거실·화장실·안방·현관 같은 위치 글자로 맞춥니다. 헷갈리면 비워 둡니다 (틀린 번호보다 빈칸이 안전).

정리

  • 기사 앱 품목 이름 아래에 🎞 필름 번호 표시
  • 먼저: 정산 품목 견적에서 그 품목에 고른 필름 (전체 자재 그대로면 아래 자동 짝)
  • 그다음: 현장관리 앱 필름 줄의 시공위치 글자와 품목 이름이 맞으면 자동 ("자동" 작게 표시)
  • 둘 다 없으면 "필름 번호 없음" — 사장님이 따로 고르는 일은 없음
