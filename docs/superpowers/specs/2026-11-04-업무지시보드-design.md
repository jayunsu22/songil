# 📝 업무지시 보드 — 통화로 들은 현장 정보를 앱에 바로 (2026-11-04)

사장님 11/4:
- 업자가 **통화로** 세대 비번 변경 등을 알려 줄 때도 앱 칸이 실제로 바뀌어야 한다.
- 김정헌 카톡방은 여러 용도로 쓰고, 노트북을 거치면 늦어진다. 그 방은 되도록 쓰지 않는다.
- 업무지시 보드를 따로 두고, 지시와 처리 내역을 거기서 관리한다.

## 결정

- **위치**: 폰 메인(홈 화면)에서 바로 연다.
  - `order.html`은 `schedule.html`과 같은 얇은 페이지이고, 열면 `index.html#order`로 간다. 홈 화면에 추가하면 업무지시 아이콘으로 보인다.
  - 앱 아이콘을 길게 누르면 manifest 바로가기 `📝 업무지시`가 나온다.
  - 앱 안에서는 내 앱 패널 `📝 업무지시`로 들어간다.
- **범위**: 현장 정보만 다룬다. 공동현관 비번, 세대 비번, 화장실, 필름, 잔금.
- **적용**: AI가 현장을 확실히 맞추면 바로 바꾼다. 카드에 `전 값 → 새 값`과 [↩ 되돌리기]를 단다.

## 흐름

1. 앱 `#order`에 지시를 쓰고 [📨 지시하기]를 누른다. 예: "류춘화 미래타운 세대비번 2222 로 바뀜"
2. 앱이 n8n **카톡_비서**(`POST kakao-assist`, 사장님 열쇠 `x-owner-key`)를 `mode: 'boss'`로 바로 부른다. 노트북과 카톡은 거치지 않는다 (약 7초).
   - prompt.js `boss`: 글에 이름이 나온 거래처의 현장만 본다 (없으면 모든 업체). 최대 60곳, 거래처 이름을 같이 보여 주고, 답장은 쓰지 않는다.
   - result.js `boss`:
     - 후보가 없으면 아무 현장이나 내밀지 않고 `missed`로 돌려준다.
     - `reply`는 늘 `null`이다.
3. 앱이 결과를 처리한다.
   - `fills`: `Kakao.fillPatch`로 그 자리에서 칸을 바꾼다. 출처는 '업무지시 11/4'.
   - `pays`: `payDone`으로 표시한다.
   - `picks`: 후보 현장 버튼을 보여 주고, 누르면 적용한다.
   - `missed`: "거래처·아파트 이름을 같이 써서 다시".
4. 처리 내역은 이 기기 localStorage `orderBoard`에 최근 100건을 남긴다.
   - 카드 상태: ✅ 처리됨 / ↩ 되돌림 / ❓ 어느 현장? / ⚠️ 못 찾음 / ⚠️ 이 기기에 없는 현장 / 🤔 넣을 정보 없음.

## 안 한 것

- 김정헌방 메모를 읽어 바꾸는 노트북 경로: 만들다가 사장님 말씀으로 뺐다.
- 처리 내역을 여러 기기에서 같이 보기: 지금은 이 기기에만 남는다. 현장 칸은 평소처럼 동기화된다.
- 일반 업무지시(문자 보내기, 할 일 등): 다음 단계.
