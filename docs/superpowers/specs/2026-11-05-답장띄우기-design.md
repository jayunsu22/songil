# 답장 띄우기 — 🤖 비서 대화에 업체·고객 답과 처리 결과 (2026-11-05)

사장님: "문자도 카톡과 마찬가지로 문자보내고, 답장을 띄우고, 처리결과를 보여줘"

## 흐름
- **알림함**: 현장관리_빈칸 `work-log` 에 `feed_add` / `feed_list {after}` (`sd.feed`). 7일·200건. 글 원문이 들어 있으므로 업무 내역(값 없음)과 따로 두고 사장님 열쇠로만 읽는다.
- **카톡**: 노트북 `worklog.feed` 를 `gaps._answer`(물어본 방의 답), `assist.handle`(지켜보는 고객 방, 또는 넣거나 올린 것이 있을 때)에서 부른다. 잡담은 안 올린다.
- **문자**: 새 흐름 문자_답장 `sms-reply`.
  - `watch`: 앱이 문자를 보내면 번호·이름·현장·못 받은 칸을 14일 기억.
  - `in`: 인원모집 `답장` 노드가 모집 답이 아닌 문자를 넘긴다(웹훅을 새로 등록하지 않음). 기억한 번호만 처리, 나머지는 저장 없이 버린다.
  - 고객(현장 있음): 카톡_비서 AI(그 현장만) → 우편함 → 알림함 → 텔레그램(값 없이). 문자로 자동 회신은 안 한다.
  - 팀원·현장 없음: AI 없이 글만 띄운다.
- **앱**: 비서 화면을 열 때와 열어 둔 동안 30초마다 가져와 대화에 붙인다(`chatFeedAt` 이후만). 🎤 켠 동안은 소리로, 글 원문은 안 읽는다. 대화에 붙으므로 비서 AI 도 이어서 알아듣는다.

## 정한 것
- 필름 번호 변경은 전처럼 사장님이 직접(자동 안 함). AI 가 확신 못 한 값은 안 넣고 "직접 넣어 주세요" 로 알린다.
- 앱·비서로 보내지 않은 번호의 문자는 띄우지 않는다(가족·다른 업체 문자 보호).
- 모집 답은 모집 쪽이 먼저 처리하고 넘기지 않는다.
