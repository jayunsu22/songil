# 간편견적 진입 UX 개편 — 설계 문서

**날짜:** 2026-08-26
**대상 저장소/브랜치:** `jayunsu22/songil`, 작업 브랜치 `feature/simple-quote-button` (main에서 분기)
**대상 파일:** `index.html`, `index_app.js`, `index_style.css` (1. 웹_배포파일 (GitHub) 폴더)

## 배경

현재 라이브 페이지(`1film.co.kr/songil`)는 첫 방문 시 웰컴 카드 아래에 `평형별 / 품목별 / 사진견적` 3탭 간편견적 패널이 강제로 펼쳐진 채(inline) 노출되고, 대화가 한 번이라도 시작되면 그제서야 `🛠️ 간편견적 열기`라는 가로 전체폭 배너 버튼으로 바뀌어 채팅 입력창 바로 위에 끼어든다.

한편 채팅창에 사진 없이 텍스트만("화장실문2개, 샤시2개" 등) 입력해 전송해도 이미 정상적으로 견적이 계산되어 나온다(`index_app.js`의 `sendRequest()`가 이미지 유무와 무관하게 텍스트만으로도 동일하게 `CONFIG.estimateUrl`에 전송함). 즉 백엔드(n8n)나 프론트의 전송 로직은 손댈 필요가 없고, 문제는 이 방식이 화면에서 전혀 안내되지 않아 아무도 쓰지 않는다는 점과, 탭 패널이 화면을 과도하게 차지한다는 UX 문제다.

## 목표

1. `평형별/품목별/사진견적` 패널은 없애지 않고 유지하되, **항상(첫 방문 포함) 우측 하단의 작은 아이콘 버튼**으로 축소해서 채팅 입력창을 가리지 않게 한다.
2. 이미 작동하는 채팅 텍스트 견적 입력 방식을 사용자가 알아채고 쓸 수 있도록 **웰컴 카드/입력창에 안내 문구**를 추가한다.
3. 지금의 라이브 상태는 그대로 보존하고, 작업은 별도 브랜치에서 진행한 뒤 확인 후 main에 반영한다.

## 비목표 (건드리지 않는 것)

- n8n 워크플로우, 견적 계산 로직, Airtable 연동 — 변경 없음
- `평형별/품목별/사진견적` 패널 내부 동작(장바구니, 평면도 핀 견적 등) — 변경 없음
- `sendRequest()`의 전송/파싱 로직 — 변경 없음 (이미 텍스트만으로 정상 동작 확인됨)

## 변경 사항

### 1. 진입 버튼: 상시 축소된 작은 아이콘 버튼

- `index_app.js`의 `renderQuickQuoteModal()`에 있는 `isInline = (chatHistory.length === 0)` 분기를 제거한다. 첫 방문이든 대화 중이든 항상 "모달 팝업 모드"로 통일 — 인라인 강제 노출(`quick-quote-inline-container`)은 더 이상 만들지 않는다.
- `addOpenQuickQuoteButton()`이 만드는 버튼을 다음과 같이 바꾼다:
  - 현재: `display:block; width:90%;` 가로 배너, `chat-input-area` 바로 위에 문서 흐름상 삽입 → 삭제
  - 변경: 작은 원형/알약형 아이콘 버튼(예: "🛠️ 간편견적"), `position: fixed; right: 14px; bottom: <입력창 높이 + 여백>px;` 로 채팅 입력창 위 구석에 떠 있게 함. 입력창을 가리지 않는지 모바일 뷰포트(375px)에서 확인.
  - 클릭 시 동작은 기존 모달 오픈 로직(`renderQuickQuoteModal()` → 모달 브랜치)을 그대로 재사용.
- `renderWelcomeIfNeeded()`가 렌더링하는 웰컴 카드 자체(인사말 + 3개 원형 아이콘 장식)는 유지하되, 그 아래에 있던 인라인 패널 강제 노출만 없앤다.

### 2. 발견성: 채팅 텍스트 입력 안내

- 웰컴 카드(`renderWelcomeIfNeeded()`)에 안내 문구 한 줄 추가: 예) "💬 또는 채팅창에 바로 '화장실문2개, 샤시2개'처럼 입력해보세요!"
- 채팅 입력창(`index.html`의 `#userInput`) placeholder 텍스트를 예시가 담긴 문구로 변경 (예: "예: 화장실문2개, 샤시2개").

### 3. Git 브랜치 전략 (백업 겸용)

- 현재 `main` HEAD에 태그 `backup-live-20260826` 생성 후 GitHub에 push — 언제든 이 시점 코드로 되돌릴 수 있는 고정 스냅샷.
- 작업은 `feature/simple-quote-button` 브랜치에서 진행. 완료 후 로컬/모바일에서 테스트 → 문제 없으면 `main`으로 병합 후 push(배포). 마음에 안 들면 브랜치를 버리면 라이브(`main`)는 전혀 영향 없음.

- [ ] 우측 하단 작은 버튼이 모바일(375px) 화면에서 입력창을 가리지 않는지 확인
- [ ] 버튼 클릭 시 기존 모달(평형별/품목별/사진견적)이 정상적으로 열리는지 확인
