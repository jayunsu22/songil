# 📋 결재함 · 매일 저녁 7시 「내일 업무일정표」 — 설계 (2026-11-03, 사장님과 정함)

목업: `docs/superpowers/mockups/approval_mockup.html` — **A안(내 앱 메뉴의 결재함) + C안 카톡 글**.

## 흐름
1. **저녁 7시** — n8n `업무일정표` 흐름이 Airtable 백업(현장·설정·할일)을 읽고, 앱의 `share.js` 를 그대로 붙여
   `Share.dailyReport(sites, settings, tasks, today)` 로 보고서를 만든다 → n8n 저장 공간 `sd.reports[내일날짜]`.
2. **카톡 김정헌방** — 보고서 요약 + 👉 결재 링크(`…/sitenote/#approve/YYYY-MM-DD`) 를 `sd.outbox` 에 둔다.
   노트북(kakao_reader) 이 돌 때마다 가져가 카톡 방(config `report_room`, 기본 '김정헌') 에 보낸다. 7시에 노트북이 켜져 있어야 한다.
3. **결재함** — 앱 `#approve` 화면. 「내 앱」 패널 맨 위 '이 앱에서' 칸에 **📋 결재함 (남은 수)**. 링크로 열어도 같은 화면.

## 보고서 내용 (`Share.dailyReport`)
- **오늘 업무 결과** (오늘 날짜): 보낸 필름 주문(`site.filmOrders` at=오늘), 받은 입금(정산 기록 입금일=오늘),
  끝낸 할 일(`task.doneAt` 오늘), 이 흐름이 오늘 한 일(9시 실행 기록: 필름 주문 문자·모집 시작).
- **내일 업무 예정** (내일 날짜) — 항목마다 `{ id, kind, title, res, siteId, act }`:
  - 필름 발주 · 인원 모집 · 실리콘/자재 · 차 보충 · 대기 인원 배정 = 앱 자동 할 일(`autoTasks`) 과 같은 기준
  - AS 방문 = AS·추가작업 날짜가 내일
  - 출입정보 질문 = 시공 7일 전인데 공동현관·세대 비번·화장실이 빈 현장
  - 잔금 받기 = 시공이 끝난 지 14일 안인데 입금 기록이 하나도 없는 현장
  - 내일 날짜로 적어 둔 할 일 (끝내지 않은 것)

## 버튼 (항목마다 3개)
- **[진행해]** — 정해진 시간에 그대로. 필름 발주는 누를 때 거래처·담당자를 고른다.
  - 필름 발주 → 다음 날 **오전 9시** 고른 담당자에게 주문 문자 (SMS Gateway) + 앱 '필름 주문' 기록(우편함 `filmOrdered`)
  - 인원 모집 → 다음 날 **오전 9시** 여러 날 모집 시작 (`Share.recruitMulti` → crew-recruit start)
  - 나머지(질문·AS·잔금·자재·할 일) → '확인함' 표시만 (질문은 지금처럼 노트북 [시작해] 알림)
- **[다음날로 연기]** — 내일 9시에 아무것도 하지 않는다. 그 일이 남아 있으면 다음 보고서에 다시 올라온다.
- **[내가할께]** — 비서는 손대지 않고, 그 날짜 앱 할 일로 넣는다(우편함 `task`).
- 아무것도 안 누르면 → 지금처럼 진행 (필름·모집은 자동 실행 안 함 — 지금도 사장님이 누를 때 하므로).

## 주소 (n8n `업무일정표`, 사장님 열쇠)
- `POST report { action: 'get', date? }` → 보고서 + 결재 (date 없으면 가장 최근)
- `POST report { action: 'decide', date, id, act: 'go'|'later'|'mine'|'', to?: { label, phone } }`
- `POST report { action: 'outbox' }` → 노트북이 보낼 카톡 글 (가져가면 지운다)
- `POST report { action: 'make' }` → 지금 바로 보고서 만들기 (시험용)
- 저녁 7시·오전 9시 시계.
