# 카톡 읽기 프로그램 — 설계 (2026-10-29, 사장님 승인)

인계 문서 `D:\n8n_거래처별_현장관리\docs\업무자동화_프로젝트.md` 8절 '다음 할 일 1번'.
카톡 전용 노트북에서 돌면서 정한 방의 **새 글·사진만** n8n 으로 넘긴다. 읽기만 한다 (보내기는 범위 밖).

## 방법 (비교 후 선택)
- 선택: **PC 카톡 채팅창의 글을 복사** (창 핸들 `EVA_VH_ListControl_Dblclk` 에 Ctrl+A·Ctrl+C 를 PostMessage → 클립보드).
  창을 앞으로 띄우지 않고 된다 (10/29 김정헌 창 489줄 확인). 공식 카톡 화면에서 복사만 하므로 정지 위험 낮음.
- 안 씀: 대화 내보내기(수동·사진 없음), 카톡 통신 흉내 도구(node-kakao 등, 정지 위험), 알림 읽기(글 잘림·나와의 채팅 알림 없음),
  카톡 DB/캐시 복호화(`chatLogs_*.edb`, `*.cng` 암호화 — 약관 위험).
- 사진: 복사에는 글 `사진` / `사진 N장` 만 나온다. 사진 파일은 **'문서\카카오톡 받은 파일' 에 새로 생긴 파일**을 가져간다.
  저장은 프로그램이 새 사진 말풍선을 더블클릭 → 뷰어 Ctrl+S → 저장 창에 폴더 지정 (창이 화면에 보여야 함, 10/29 2장 확인). 사장님이 손으로 저장해도 같이 넘어간다.

## 구성 (`kakao_reader/`, 파이썬 표준 라이브러리 + 사진 찾기용 Pillow)
| 파일 | 하는 일 |
|---|---|
| `kakao_text.py` | 순수 함수: 복사 글 → 메시지 목록, 메시지 지문(날짜·보낸이·시각·내용·같은 분 순번 → sha1 앞 16자), 새 메시지 고르기, 비번 가리기, 사진 수 |
| `kakao_window.py` | 윈도우 API(ctypes): 방 창 찾기(제목=방 이름), 글 복사, 클립보드 읽기·되돌리기 |
| `kakao_photo.py` | 받은 파일 폴더에서 새 사진 고르기, 말풍선 더블클릭 → 뷰어 저장 |
| `n8n_send.py` | multipart POST (`x-owner-key`), 글 JSON + 사진 파일 |
| `reader.py` | 주기 실행(기본 60초), `config.json`(gitignore) 읽기, `state.json` 에 지문만 저장 |
| `test_kakao_text.py` | `python -m unittest` |

## 규칙
- 이미 읽은 글은 다시 안 보냄: 방마다 지문 집합(최근 2000개)만 `state.json` 에 저장 — **글 내용은 노트북 파일에 남기지 않는다**.
- **처음 실행**: 지금 보이는 글은 모두 읽음 처리만 하고 보내지 않는다 (지난 대화의 비번·사업자등록증이 나가지 않게).
- 날짜 줄 앞(날짜 모르는) 메시지는 보내지 않는다.
- 비번 가리기(기본 켬): `비번/비밀번호/공동현관/현관/세대/도어락/#` 근처 숫자 3자리 이상 → `●●●●`.
- 새 메시지가 없으면 아무것도 보내지 않는다 (AI 사용 0). 프로그램 자체는 AI 를 부르지 않는다.
- 보내기 실패 시 지문을 저장하지 않아 다음 주기에 다시 보낸다.
- 정한 방만 (`config.rooms`). 시험은 `김정헌` 만.

## n8n `카톡_받은글` (POST `kakao-inbox`, 사장님 열쇠)
- 받는 것: `payload`(JSON: room, messages[{date,time,sender,text,photos}], sentAt, reader) + `photo0..N` 파일.
- 지금은 받고 `{ok, count, photos}` 로 응답만 (실행 기록에 남음). 견적 문의 가르기·초안은 다음 단계.
- 원본 `n8n/kakao_inbox/build.js` (견적초안_읽기처럼). 열쇠 없이 시험 → `--auth` 로 켬.
