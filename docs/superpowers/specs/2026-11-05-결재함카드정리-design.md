# 결재함 카드 자동 정리 · 홈 화면 아이콘 (2026-11-05 사장님 승인)

사장님: 필름 주문과 출입정보를 끝냈는데 결재함 카드가 그대로 남아 있었다. "함께 고쳐 배포".

## 원인
보고서는 전날 만든 그대로이고, 카드는 결재함 [완료]를 눌러야만 사라졌다. 현장 화면·카톡으로 끝낸 일은 카드에 반영되지 않았다. [되돌리기]는 카드만 되살리고 앱 기록은 남겼다.

## 자동 CLEAR
`Share.reportItemDone`: 카드를 그릴 때 지금 앱 내용과 맞춰 본다. 저장하지 않고 그때그때 계산한다.
- 필름·인원·실리콘·자재·차 보충·대기 인원: 같은 날짜로 `autoTasks` 를 다시 돌려 없으면 끝.
- 출입정보: 공동현관·세대 비번·화장실이 다 있으면 끝. 잔금: `payDone` 또는 입금 기록. AS·할 일: 완료 표시.
- 고객 후기·안부 인사: 사람이 정할 일이라 자동으로 끝내지 않는다.

자동 CLEAR 카드에는 되돌리기가 없다. 잘못됐으면 그 현장에서 고친다. 미션 수, 결재함 숫자, [남은 미션 모두 진행]에서 함께 뺀다.

## 되돌리기
[완료]를 취소하면 확인을 받고, 우편함 `undo` 로 앱 기록도 되돌린다 (잔금·AS·할 일·직접 주문 기록). 결과 목록에서도 뺀다. 완료·되돌리기 뒤에는 우편함을 바로 받아 오고, 우편이 들어오면 보고 있던 결재함을 다시 그린다.

## 9시 실행
[진행해]로 결재한 뒤 앱에서 이미 끝낸 필름 주문·인원 모집은 다시 하지 않는다 (필름 문자 중복 방지).

## 홈 화면 아이콘
`approve.html` + `manifest-approve.json`, 업무지시와 같은 방식. 앱 `#approve` 화면에서도 결재함 앱으로 설치된다.
