# 📋 업무 내역 — 진행 내역을 한곳에 (2026-11-04)

사장님 11/4: "업무 진행 내역을 한곳에 모아볼 수 있으면 좋겠다." 목업: `docs/superpowers/mockups/work_log_mockup.html` ("이대로 만들어").

## 화면

🤖 비서 화면에 탭 두 개: 💬 대화 / 📋 업무 내역.
- 필터: 전체 / 확인 필요 / 문자 / 현장 정보 / 필름·인원. 날짜별로 묶고, 누가 시작했는지(내 지시·비서 자동·결재함·인원모집·필름 주문)를 표시한다.
- 확인 필요 줄에는 [확인함]이 있다. 목업에는 없었지만, 누를 곳이 없으면 줄이 계속 쌓여서 넣었다.
- 현장이 이 기기에 있으면 현장 이름을 보여 주고, 누르면 그 현장으로 간다.

## 저장

n8n **현장관리_빈칸** 흐름의 저장 공간 `sd.worklog`. 새 주소 `POST work-log` (사장님 열쇠): add / list(최근 500) / resolve. 90일 · 2000건까지.

우편함(`put.js`)과 같은 흐름에 둔 이유: 우편함을 거치는 일(칸 넣기·필름 주문·인원·잔금·AS·할 일)은 다른 흐름을 고치지 않아도 자동으로 적히기 때문이다.

| 어디서 | 어떻게 적나 |
|---|---|
| 우편함을 거치는 일 (노트북 칸 넣기, 결재함 완료·필름 주문, 인원 넣기, 결재함 카드) | `put.js`가 값 없이 적음 |
| 결재함 9시 실행의 실패·인원 모집 시작 | 우편에 `kind: 'log'` (앱 우편함에는 안 들어감) |
| 🤖 비서에게 시킨 일 | 앱이 실제 결과로 add (`BossChat.logItems`) |
| 앱 📨 바로 주문 | 앱이 add |
| 노트북 자동 답장·답장 초안·필름 변경 요청 | `worklog.py`가 add. 답장을 보내면 초안 줄은 확인됨으로 |

비번 값은 적지 않는다. 노트북이 보내는 글은 `kakao_text.mask`로 가린다. 저장 공간은 동시에 쓰면 드물게 한 줄이 빠질 수 있다 (내역이라 감수).

## 안 적는 것

- 텔레그램 버튼으로 보낸 필름 주문 문자가 **실패**한 경우: 우편이 안 생겨 내역에 없다 (텔레그램에는 실패가 표시됨).
- 앱 화면에서 직접 고친 일: 비서를 거치지 않으니 안 적힌다.

## 예전 내역

이 기기의 업무지시 카드와 비서 대화 결과만 처음 화면을 열 때 한 번 옮긴다 (`workLogMoved`). 비번 값은 잘라 낸다.

## 같이 고친 것

- **결재함 [완료표시]가 앱에 반영되지 않던 문제:** 우편함(`put.js`)이 `kind: 'done'`을 모르는 종류로 버리고 있었다. 받게 고쳤다. 고치기 전에 누른 완료표시는 우편이 이미 버려져 되살릴 수 없다.
- 비서 문자 확인: "보내 보내"처럼 되풀이한 말도 알아듣는다.
