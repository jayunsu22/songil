## 흐름

- **n8n 현장관리_빈칸**(u0jKTp2YsiRj4POE): 업무 내역(`sd.worklog`)과 답장(`sd.feed`)이 이 흐름에 있어서 같은 흐름에 붙였다.
  - `매시정각` (cron `0 * * * *`) → `정시보고`(report.js).
    - 흐름에 시간대 설정이 없어서, 코드에서 한국 시간으로 시간·요일을 본다.
    - 설정 기본값: 8~17시, 토요일 켬, 일요일 끔.
  - 지난 1시간(정각~정각)을 이렇게 나눈다:
    - 처리됨: 업무 내역 중 확인 필요가 아닌 것
    - 확인 필요: 업무 내역 중 state `need`
    - 받은 답장: feed의 문자·카톡 답장
  - 일이 있으면:
    - 비서 대화 카드를 feed에 `kind: 'report'`로 넣는다. 같은 시각은 한 번만 넣는다.
    - 폰 알림: `알림목록` → `폰알림보내기`가 견적 앱의 Netlify `send-push`로 보낸다. VAPID 키와 `x-secret-token`이 견적 앱과 같다.
  - 일이 없으면 feed에 `quiet` 카드(회색 한 줄)만 넣는다. 설정에서 '일 없는 시간도 알림'을 켜면 알림도 보낸다.
- **POST `hourly-report`** (사장님 열쇠):
  - `sub { subscription }`: 이 폰 등록. 최근 5대까지 둔다.
  - `unsub { endpoint }`
  - `cfg { cfg? }`: 설정 읽기·바꾸기
  - `test`: 지금 지난 1시간으로 시험 알림을 보낸다.
- **앱 (sitenote)**:
  - sw.js `push`: 알림을 띄운다. 제목·요약·항목, 버튼은 [보고 열기] [확인 필요 보기]. 같은 tag로 바꿔 쌓이지 않게 한다.
  - sw.js `notificationclick`: `#order`(비서)를 연다. '확인 필요 보기'는 `#order/log`(업무 내역 탭)로 연다.
  - 비서 대화: feed `report`를 카드로 보여 준다(처리됨 / 받은 답장 / 확인 필요, [업무 내역 전체] [확인 필요 보기]). `quiet`는 회색 한 줄이다.
  - 비서 위 🔔 설정: 정시 보고 받기, 시간, 일 없는 시간 알림, 주말, 이 폰에서 받기(웹푸시 구독), 시험 보내기, 저장.
