# D. 인원 모집 문자 — 설계 (2026-11-01, 사장님과 정함)

현장 날짜마다 **인건비 예산**을 정하고, 고정 팀원을 넣은 뒤 **남은 예산 안에서** 팀원 순서대로 문자로 구한다.
문자는 사장님 폰(SMS Gateway, 필름 주문과 같은 것)이 보내고, 답장도 그 폰으로 받아 n8n 이 읽는다.

## 1. 앱 (현장관리, sitenote)

### 1-1. 모집 순서
- **설정 › 팀원 명단**: 이름마다 ▲▼ — 이 순서가 기본 모집 순서 (`settings.team` 배열 순서).
- **현장 › 일정·인원 › "이 현장 모집 순서"**: 기본 순서를 복사해 ▲▼ 로 바꾼다 → `site.recruitOrder = [이름…]`.
  비워 두면 기본 순서. 명단에 새로 생긴 사람은 맨 뒤에 붙는다.

### 1-2. 날짜별 예산·필요 인원
- 일차 칸마다 **예산(만원)** `day.budget` 과 **필요 인원** `day.need`.
- 그날 넣은 사람(고정 팀원 포함) 일당 합을 빼서 **"남은 예산 42만 · 남은 자리 2명"**.
- 일당은 설정 › 팀원의 '페이' (만원, 8~30). 일당이 없는 사람을 넣으면 "일당 미입력" 경고.

### 1-3. 📨 인원 모집 (일차 칸마다)
후보 = 모집 순서대로, 아래를 뺀 사람:
- 그날 이미 어느 현장·AS 에 들어간 사람, 그날 대기 인원으로 잡힌 사람
- 번호·일당이 없는 사람
- **남은 예산을 넘는 사람** — 이 사람을 넣으면 남은 자리를 남은 후보 중 가장 싼 사람들로 채워도 예산을 넘을 때
  (예: 42만·2자리 → 25+17 ✅, 25+23 ❌).

앱은 후보 목록(이름·번호·일당, 순서대로)과 날짜·자리 수·남은 예산을 n8n `crew-recruit` 로 보낸다.
문자에 **일당·현장명은 넣지 않는다**.

## 2. n8n (카톡_버튼 흐름 — 텔레그램 버튼을 받는 곳이 여기 하나뿐이라)

저장 공간 `sd.recruits[번호] = { siteId, date, slots, budget, queue:[{name, phone, pay}], asked:{phone: {at, tries}}, got:[…] }`.

### 문자 (사장님이 정한 그대로)
- 묻기: `안녕하세요~\n11/5(목) 일정 가능하신가요?\n가능하시면 "네", 일정 안되시면 "아니요"라고 해주세요~`
- '네' → 텔레그램 확인 뒤 [넣기] 를 누르면: `네~ 감사합니다.\n주소확정되면 보내드릴께요~`
- '아니요' → 바로: `아쉽네요~ 담에봐요~`
- 2시간 답 없음 → **한 번 더** 같은 묻기 → 또 2시간 없음 → `연락이 없어서 다른분께 연락드릴께요.\n담에봐요~`

### 흐름
1. 시작: 남은 자리 수만큼 순서대로 묻기 (4자리면 4명, 3자리면 3명).
2. 답장(SMS Gateway `sms:received` 웹훅 → `sms-in`): 보낸 번호로 그 모집을 찾는다.
   - '네·예·넵·가능·ㅇㅇ' → 텔레그램 **"👤 서영호(23) 11/5 가능 — [넣기] [안 넣기]"**.
     [넣기] → 감사 문자 + 우편함(site-fill) `crewAdd` → 앱이 그날 인원에 넣음, 남은 예산 다시 계산.
     [안 넣기] → 문자 없이 다음 사람.
   - '아니요·안돼요·안되요·불가' → 아쉽네요 문자 + 다음 사람 1명.
   - 둘 다 아니면 → 텔레그램에 원문 + [넣기] [안 넣기] (사장님이 판단).
3. 10분마다 시계: 2시간 지난 사람 → 다시 묻기(2번째) 또는 '연락이 없어서…' + 다음 사람 1명.
4. 다음 사람을 고를 때 남은 예산·남은 자리로 다시 거른다 ([넣기] 된 사람 일당만큼 줄어든 예산).
5. 후보가 다 떨어지고 자리가 남으면 → 텔레그램 **"모두 안 됨 — 밴드에서 구해 주세요"** + 밴드 글(`buildRecruitText`).
6. 자리가 다 차면 남은 대기자에게는 보내지 않는다 (이미 물어본 사람이 늦게 '네' 하면 텔레그램으로만 알림).

### 시간
- 시계(2시간 다시 묻기·무응답 넘기기)는 **오전 8시~저녁 8시**에만. 밤에 걸린 2시간 기다림은 다음 날 8시부터 다시 센다.
- 사장님이 📨 를 누를 때·팀원이 답할 때 보내는 문자는 그때 바로.

## 만든 것 (2026-11-01)
- 앱 sitenote 20261101h: `Share.recruitPlan`·`pickWithinBudget`·`recruitOrderOf`, 일차 칸 예산·필요·남은 예산·📨·진행, 🔢 현장 순서, 설정 팀원 ▲▼, 우편함 `crewAdd`.
- n8n `인원모집` (rstpDq5oFteXjL7z): crew-recruit(start·status·stop) · 받은 문자 웹훅 · crew-act(카톡_버튼 [넣기]·[안 넣기]가 넘김) · 10분 시계. 코드 `n8n/crew_recruit/`, 시험 `node n8n/crew_recruit/test.js`.
- SMS Gateway 받은 문자 웹훅 등록함 (crew-sms-hook 로 한 번).

## 3. 처음 한 번 (사장님)
- SMS Gateway 에 받은 문자 웹훅 등록 — n8n 이 한 번 부르는 등록 흐름으로 (아이디·비번은 n8n 자격증명에만).

## 4. 안 하는 것 (이번에는)
- 일당 협상, 현장 주소 보내기(“주소확정되면” — 사장님이 직접), 밴드 자동 글쓰기.

## 시험
- 앱: 후보 거르기(예산 조합·겹치는 날·순서) 단위 테스트, 남은 예산 표시.
- n8n: 사장님 번호를 후보로 넣고 네/아니요/무응답(시계를 당겨서) 한 번씩.
