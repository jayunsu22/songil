# 인건비 예산 · 직접 구인 · 고른 사람에게만 문자 (2026-11-06 사장님 승인)

"예산은 참고자료", "직접 구인이 안 채워지면 계속 업무로", "내가 선택한 사람들만 문자".

## 인건비 예산
`site.laborBudget` (만원, 0 = 미정). 현장에 하나, 드롭다운 미정·20~300만 10만 단위. 언제든 다시 고른다. 참고용이라 모집을 막지 않는다. 배정 페이 합계와 나란히 보여 준다. 예전 날짜별 예산은 쓰지 않고 옮기지도 않는다.

## 필요 인원
위쪽 '날짜별 인원'과 총 필요 인원 칸을 없앴다. `needStaffOf` 는 날짜 카드(`dayPlan[iso].need`) 합계, 없으면 예전에 적어 둔 `needStaff`. 일정 표기·부족 표시는 이 값을 그대로 쓴다. 추가작업의 필요 인원 넣기는 날짜별 현장이면 마지막 날에 더한다.

## 직접 구인
`dayPlan[iso].selfHire`. 그 날은 문자에서 빠지고(`recruitMulti`), '문자로 구할 수'(`recruitShort`)에서도 빠진다. 다 채울 때까지 시공일이 지나기 전까지 날마다 자동 할 일 `selfhire` → 결재함 카드. 필요 인원을 안 정했으면 아무도 없을 때 1명으로 본다. 다 차면 `reportItemDone` 으로 저절로 끝난다. 카드 버튼: 현장 열기, 문자 모집으로.

## 고른 사람에게만 문자
`recruitPickOf`: 현장의 `recruitOrder`, 없으면 설정 `recruitPick`(백업됨). 누른 순서가 문자 순서이고, 안 고른 사람은 받지 않는다. 아무도 없으면 모집 시작 버튼이 막히고, 9시 [진행해]는 텔레그램으로 알린다. 예산·일당으로 거르지 않는다(번호는 있어야 한다). 서버 `start.js` 의 일당 조건도 뺐다. 서버의 예산 규칙은 budget 0 으로만 불린다.

## 정렬 스위치
설정 › 팀원 `teamSortPay`·`teamSortGrade`. 보기용이며 이 기기에만 저장. 둘 다 켜면 등급 → 페이 높은 순. 고르기 창 목록도 같은 정렬을 따른다.

## 날짜별 답
바꾸지 않았다. 되는 날만 잡고 안 되는 날은 다음 사람에게, 텔레그램 [넣기]로 넣는다.
