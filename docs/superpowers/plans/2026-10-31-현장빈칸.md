# 현장 빈칸 채우기 A·B Implementation Plan

> 실행자: 같은 세션 인라인 (writing-plans-extras — 인터페이스·시험만 적고 코드는 파일에 바로).

**Goal:** 시공 1주 전 빈칸(공동현관·세대 비번·화장실·필름) → 텔레그램 [시작해] → 업체 방 질문 → 답을 현장관리 앱 칸에 (우편함).
**Architecture:** n8n 새 흐름 현장관리_빈칸(site-gaps·site-fill·site-fill-take) + 카톡_버튼 ask + 노트북 gaps.py + sitenote fill.js.
**설계:** `docs/superpowers/specs/2026-10-31-현장빈칸-design.md`

## Global Constraints
- 질문 첫 줄 `안녕하세요. 실장님~` (사장님 10/31).
- 8~20시만 묻기, 현장당 한 번, 답 7일, 우편함 14일, 앱 5분마다.
- 노트북 파일에 글·비번 남기지 않음. push·sitenote 배포는 사장님께 묻기.

### Task 1: n8n 현장관리_빈칸 + 카톡_버튼 ask
**Files:** Create `n8n/site_fill/{build.js,gaps.js,put.js,take.js,workflow.json}`; Modify `n8n/kakao_buttons/pressed.js`
**Interfaces (Produces):**
- POST `site-gaps` (사장님 열쇠, body `{today, days:7}`) → `{sites:[{id, client, name, date, missing:[pwLobby|pwUnit|toilet|films], known:{}}]}`
- POST `site-fill` body `{fills:[{siteId, kind:'field'|'films', field?, value, films?, room, at}]}` → `{ok, n}`
- POST `site-fill-take` body `{done:[id]}` → `{fills:[{id, siteId, kind, field, value, films, room, at}]}` (done 지우고, 14일 지난 것 지움)
- 카톡_버튼 콜백 `k|번호|ask` → jobs `{job, action:'ask'}`
**Test:** 배포 뒤 site-gaps 실제 호출(목록 모양), site-fill → take → done 왕복.

### Task 2: 노트북 gaps.py
**Files:** Create `kakao_reader/gaps.py`, `kakao_reader/test_gaps.py`; Modify `jobs.py`(ask), `n8n_send.py`(post_json), `reader.py`(1시간마다 check, poll run), `chatlist.py`(read_and_report → gaps.on_answer, 알릴 방에 asks 방 더하기)
**Interfaces:**
- `gaps.room_for(cfg, client) -> str|None` (client_rooms, 대소문자·띄어쓰기 무시)
- `gaps.question(site) -> str`, `gaps.ask_text(site) -> str` (텔레그램)
- `gaps.check(cfg, state, now, fetch, notify, log)` — 시간 거르기·한 번만·job 만들기 (`state.jobs[job] = {kind:'빈칸', site}`)
- `gaps.run_ask(cfg, state, job, info, notify, log)` — 방 열기·send_text·`state.asks[room]`
- `gaps.watch_extra(state, now) -> [room]`
- `gaps.on_answer(cfg, state, room, msgs, digest, put, notify, log)` — digest → 거르기 → put → 알림, asks 정리
- `gaps.pick_fills(items, asked) -> [fill]` (pwLobby·pwUnit·toilet·films, 물어본 현장 id 만)
**Test (test_gaps.py):** 8~20시 밖이면 안 물음 / 한 번만 / 방 짝 없으면 버튼 없는 알림 한 번 / 질문 글(빈칸만, 첫 줄) / pick_fills 거르기 / on_answer 다 받으면 asks 에서 뺌 / 7일 지난 asks 지움 / 비번이 state 에 안 남음.

### Task 3: sitenote 우편함
**Files:** Create `fill.js`, `test/fill.test.js`; Modify `app.js`(가져오기·넣기·토스트), `index.html`(script), `sw.js`(캐시 목록·버전), `owner-key.js`(+ songil 복사본) 경로 `site-fill-take`
**Interfaces:** `Fill.patchFor(site, fill, today) -> {patch, label}|null` (field → 값+fieldSrc, films → mergeFilms+fieldSrc)
**Test:** node test/fill.test.js — field·films·없는 현장 null.
