# 카톡 버튼 (3단계) Implementation Plan

> 실행자: **같은 세션이 곧바로 인라인 실행** — 파일 맵·계약·시험만 적고 코드는 파일에 바로 쓴다.

**Goal:** 텔레그램 요약에 버튼을 붙이고, [가견적 발행] 을 누르면 노트북이 그 방 글·사진으로 가견적을 내 링크를 텔레그램으로 보낸다.
**Architecture:** n8n 카톡_버튼(텔레그램 트리거) 이 누름을 받아 Data Table `카톡_할일` 에 적고, 노트북이 n8n 카톡_할일(POST kakao-jobs) 로 가져가 처리. 설계: `docs/superpowers/specs/2026-10-31-카톡버튼-design.md`.
**Tech Stack:** n8n (webhook·telegram·telegramTrigger·dataTable), Python 3.12 표준 라이브러리 + 기존 kakao_reader 모듈.

## Global Constraints
- 노트북 파일에 글 내용 저장 금지 — `state.json` 에는 지문(key)만.
- 카톡 보내기는 김정헌 방만. 가견적 링크는 텔레그램으로만.
- 열쇠는 사장님 열쇠(headerAuth `Tm4pgTszEk1zUiQ8`) 만. 봇 자격 `4iGW8eEwhNuTpFHa` 는 n8n 안에만.
- 콜백 데이터 `k|<번호6자>|<동작>` (텔레그램 64바이트 한도), 동작 = `pub` | `later` | `ok`.

### Task 1: n8n — 버튼 보내기·받기·할일
**Files:** `n8n/kakao_notify/build.js`(고침) · `n8n/kakao_buttons/build.js`(새) · `n8n/kakao_jobs/build.js`(새) · 각 `workflow.json`
**Interfaces:**
- Produces: POST `kakao-notify` `{text, buttons?: [[{text, data}]]}` → 버튼 있으면 인라인 키보드.
- Produces: POST `kakao-jobs` (사장님 열쇠) → `{jobs: [{job, action, at}]}` 안 가져간 것, 가져감 표시.
- 카톡_버튼: callback_query, from.id == p_001 챗ID 일 때만. answerCallbackQuery + 버튼 지우고 표시 붙이기. `pub` 만 테이블에 행 추가.
**시험:** kakao-notify 에 buttons 넣어 보내 텔레그램에 버튼이 뜨는지(이 PC, 사장님 확인), kakao-jobs 빈 목록 200.

### Task 2: 노트북 — 버튼 붙이기·할일 기록
**Files:** `kakao_reader/chatlist.py`, `kakao_reader/n8n_send.py`, `kakao_reader/jobs.py`(새), `kakao_reader/test_jobs.py`(새)
**Interfaces:**
- `n8n_send.notify(url, key, text, buttons=None) -> bool`
- `n8n_send.fetch_jobs(url, key) -> list[dict]`
- `jobs.new_job(state, title, kind, msgs, t) -> (job_id, buttons)` — state["jobs"][id] = {title, kind, keys, photos, at}; 7일 지난 것 정리.
- `jobs.buttons_for(kind, job_id) -> list[list[dict]]`
- `jobs.pick_by_keys(msgs, keys) -> list[msg]`
- `chatlist.read_and_report` 가 `notify(text, buttons)` 로 보냄 (notify 콜백이 buttons 인자를 받음).
**시험:** buttons_for(견적 문의/그 밖), new_job 지문만 저장·오래된 것 정리, pick_by_keys.

### Task 3: 노트북 — 할일 처리 (가견적 발행)
**Files:** `kakao_reader/jobs.py`, `kakao_reader/reader.py`, `kakao_reader/test_jobs.py`
**Interfaces:**
- `jobs.poll(cfg, state, notify, log, fetch, publish_job)` — 가져온 `pub` 하나씩: 이미 한 번호면 건너뜀(state["jobs_done"]), 없는 번호면 이유 알림.
- `jobs.run_publish(cfg, state, job_id, notify, log)` — 방 열기(chatlist.find_row/open_room) → 복사 → pick_by_keys → 사진 저장(kakao_photo.save_latest_photos) → 방 닫기 → quote_bot.publish(..., client=방 제목, aliases) → 링크 알림.
- reader.run_once 끝에서 `jobs.poll(...)`.
**시험:** poll 이 중복·없는 번호를 거르는지(가짜 fetch/publish), 실제 발행은 노트북에서.
