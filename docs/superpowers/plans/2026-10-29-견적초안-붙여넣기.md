# 견적초안 ①② 붙여넣기 Implementation Plan

> **실행자:** 같은 세션이 곧바로 인라인 실행 (writing-plans-extras 계약 모드 — 코드는 파일에 바로 쓴다).
> 설계: `docs/superpowers/specs/2026-10-29-견적초안-붙여넣기-design.md`

**Goal:** 견적 요청 글을 붙여넣으면 방문견적에 품목이 체크되고 꼭 알아야 할 것 중 빠진 것이 보인다.

**Architecture:** n8n 사장님 전용 흐름 `견적초안_읽기`(1분견적 텍스트 프롬프트 복사 + 공통 정보) → 순수 모듈
`request_draft.js` 가 1분견적 품목을 방문견적 `MASTER.zones` 의 체크로 바꾼다 → `quote_draft_view.js` 가 화면 칸·호출·`state.선택` 반영을 맡는다.

**Tech Stack:** 바닐라 JS(UMD 순수 모듈 + 전역 화면 스크립트), node:test, n8n(Code·HTTP·Airtable 노드), Gemini 2.5 flash.

## Global Constraints
- 1분견적 규칙: 샤시 종류 없으면 단창, 샤시 1개=3m, 가구 1세트=2m (프롬프트 그대로).
- 세트 = 문짝+문틀. 화장실문 2개 → 거실 · 방1.
- 구역 순서: 거실 · 주방 · 현관 · 방1 · 방2 · 방3 · 방4 · 방5, 그 뒤 나머지 구역은 MASTER 순서.
- `image-test` 는 부르지 않는다 (고객 견적요청 저장·텔레그램·푸시가 나간다).
- 웹훅은 열쇠 없이 시험 → 확인 뒤 headerAuth(사장님 열쇠 `Tm4pgTszEk1zUiQ8`) 켜기.
- 캐시: quote_pro.html 의 새 스크립트에 `?v=20261029a`.
- 커밋은 `claude/quote-draft` 브랜치에만. 푸시·main 머지는 사장님 확인 후.
