# 카톡 읽기 프로그램 (kakao_reader)

카톡 전용 노트북에서 돌면서 **정해 둔 방의 새 글·사진만** n8n `카톡_받은글`(POST `kakao-inbox`)로 보냅니다.
읽기만 합니다 — 카톡에 글을 보내지 않습니다. AI 도 부르지 않습니다 (새 글이 없으면 아무것도 안 보냄).
설계: `docs/superpowers/specs/2026-10-29-카톡읽기-design.md`

## 어떻게 읽나
- 카톡 채팅창(제목 = 방 이름)의 글을 **복사**해 옵니다 (Ctrl+A·Ctrl+C 를 창에 보냄). 창을 앞으로 띄우지 않고, 쓰던 클립보드는 되돌려 놓습니다.
- 사진은 카톡이 PC 안에 암호화해 두므로, **'문서\카카오톡 받은 파일' 폴더에 새로 생긴 사진**을 보냅니다.
  사진을 그 폴더에 저장하면(사진 더블클릭 → 저장, 묶음이면 '묶음사진 전체저장') 다음 확인 때 같이 넘어갑니다.
- 처음 실행 때는 지금까지의 글·사진을 **읽음 처리만** 하고 보내지 않습니다 (지난 대화의 비번·사업자등록증이 나가지 않게).
- 비번처럼 보이는 숫자(비번·현관·세대·도어락 줄의 3자리 이상 숫자)는 `●●●●` 로 가려서 보냅니다.
- 노트북에는 글 지문(짧은 암호 같은 값)과 사진 파일 이름만 `state.json` 에 남고, 글 내용은 저장하지 않습니다.

## 노트북 준비 (사장님)
1. 파이썬 3.12 설치 (python.org, 설치 때 'Add python.exe to PATH' 체크). 사진 자동 저장을 쓸 때만: `pip install pillow`
2. 이 폴더(`kakao_reader`)를 노트북에 복사 (예: `C:\kakao_reader`).
3. `config.example.json` 을 복사해 `config.json` 으로 이름을 바꾸고 메모장으로 열어 `owner_key` 에 **사장님 열쇠**를 직접 넣기.
   - `rooms`: 읽을 방 이름 (카톡 창 제목과 똑같이). 시험은 `["김정헌"]` 만.
   - `interval`: 몇 초마다 볼지 (기본 60).
4. PC 카톡 로그인 → 읽을 방마다 **채팅창을 열어 둠** (작게 해도 됨, 닫으면 못 읽음). 절전·화면 잠금 끄기.
5. 시험: 명령 프롬프트에서
   ```
   cd C:\kakao_reader
   python reader.py --dry
   ```
   → `[김정헌] 처음 실행: …` 이 나오면 창을 찾은 것. (`--dry` 는 보내지 않고 개수만 봄)
6. 실행: `python reader.py` (창을 닫으면 멈춤). 한 번만: `python reader.py --once`
7. 켤 때 자동 시작: 작업 스케줄러 → 기본 작업 만들기 → '로그온할 때' → 프로그램 `pythonw.exe`, 인수 `reader.py`, 시작 위치 `C:\kakao_reader`.

## 화면에 나오는 말
| 말 | 뜻 |
|---|---|
| `채팅창이 열려 있지 않음` | 그 방 창을 카톡에서 열어 두기 |
| `새 글 2개 · 사진 1장` → `보냄 (200)` | n8n 이 받음 |
| `보내기 실패: HTTP Error 403` | `config.json` 의 열쇠가 틀림 (열쇠를 바꿨으면 여기도 바꾸기) |
| `보내기 실패: …` (그 밖) | 인터넷 문제 — 다음 확인 때 다시 보냄 |

## 사진 자동 저장 (시험 기능, 기본 끔)
`config.json` 에서 `"auto_save_photos": true` 로 켜면, 새 글이 `사진` 일 때 그 방 창을 앞으로 띄워
맨 아래 사진을 더블클릭하고 뷰어에서 Ctrl+S 로 저장합니다. **마우스를 움직이므로 카톡 전용 노트북에서만** 켜고,
방 창이 다른 창에 가리지 않게 두세요. 아직 실제로 시험하지 않았습니다.
