# 카톡 읽기 프로그램 (kakao_reader)

카톡 전용 노트북에서 돌면서 **정해 둔 방의 새 글·사진**을 n8n `카톡_받은글`(POST `kakao-inbox`)로 보내고,
김정헌 방에 **`견적발행시작 거래처명`** 을 쓰면 그 앞 글·사진으로 현장견적 앱에서 **가견적을 발행해 링크를 그 방에 보내고 텔레그램으로 알립니다** (`send_rooms`, 지금은 김정헌 방만).
다른 업체·고객 방은 **열지 않고**, 카톡 채팅 목록에 안 읽은 숫자(빨간 배지)가 새로 생기거나 늘면 텔레그램으로 "pk디자인 방에 새 글 3개" 처럼 알립니다 (아래 '새 글 알림').
Claude 는 부르지 않습니다. AI 는 새 문의 1건에 n8n 견적초안_읽기(Gemini) 한 번뿐.
설계: `docs/superpowers/specs/2026-10-29-카톡읽기-design.md`

## 어떻게 읽나
- 카톡 채팅창(제목 = 방 이름)의 글을 **복사**해 옵니다 (Ctrl+A·Ctrl+C 를 창에 보냄). 창을 앞으로 띄우지 않고, 쓰던 클립보드는 되돌려 놓습니다.
- 사진은 카톡이 PC 안에 암호화해 두므로, **'문서\카카오톡 받은 파일' 폴더에 새로 생긴 사진**을 보냅니다.
  사진을 그 폴더에 저장하면(사진 더블클릭 → 저장, 묶음이면 '묶음사진 전체저장') 다음 확인 때 같이 넘어갑니다.
- 처음 실행 때는 지금까지의 글·사진을 **읽음 처리만** 하고 보내지 않습니다 (지난 대화의 비번·사업자등록증이 나가지 않게).
- 비번처럼 보이는 숫자(비번·현관·세대·도어락 줄의 3자리 이상 숫자)는 `●●●●` 로 가려서 보냅니다.
- 노트북에는 글 지문(짧은 암호 같은 값)과 사진 파일 이름만 `state.json` 에 남고, 글 내용은 저장하지 않습니다.

## 노트북 준비 (사장님)
1. 노트북 설정: 절전 안 함 · 덮개 닫아도 아무것도 안 함 · 화면 잠금 끄기. 백신 광고 창(V3·알약)은 카톡 창을 가리므로 지우고 Windows 보안(Defender)만.
2. 파이썬 3.12 설치: `https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe` ('Add python.exe to PATH' 체크).
   (Windows 10 1903 처럼 옛 윈도우는 'Python Install Manager' 가 안 깔린다 — 위 설치 파일을 쓴다.) 그다음 명령 프롬프트에서
   ```
   python -m pip install pillow playwright
   python -m playwright install chromium
   ```
3. 이 폴더(`kakao_reader`)를 노트북에 복사 (예: `C:\kakao_reader`).
4. `config.example.json` 을 복사해 `config.json` 으로 이름을 바꾸고 메모장으로 열어 `owner_key` 에 **사장님 열쇠**를 직접 넣기 (등록 링크째 넣어도 됨). 이 파일은 카톡으로 보내지 않기.
   - `rooms`: 읽을 방 이름 (카톡 창 제목과 똑같이). 시험은 `["김정헌"]` 만.
   - `quote_rooms`: '견적발행시작' 신호를 받는 방. `send_rooms`: 링크를 카톡으로 보낼 방 (김정헌만).
   - `client_aliases`: 거래처 별명 → 현장관리 거래처 이름 (예 `{"피케이디자인": "PK디자인"}`). 띄어쓰기·대소문자는 알아서 무시.
   - `interval`: 몇 초마다 볼지 (기본 60).
5. 현장견적 앱 열기 (처음 한 번): `python quote_bot.py --setup` → 크롬 창이 뜨면 **관리자 암호**, 이어서 '업체 선택' 창에 **백업키(숫자 6자리)** 를 사장님이 직접 넣고 [업체 불러오기] → '준비 완료'.
   (거래처 목록이 있어야 발행한 견적이 현장관리 앱 '견적요청 내역' 에 들어간다.)
6. PC 카톡 로그인(잠금모드 끄기) → 읽을 방마다 **채팅창을 열어 둠** (작게 해도 됨, 닫으면 못 읽음).
   **카톡 메인 창도 '채팅'(말풍선) 탭으로 열어 둠** — 다른 창 뒤에 있어도 되지만 **최소화(_)는 안 됨** (새 글 알림이 못 봄).
7. 시험: 명령 프롬프트에서
   ```
   cd C:\kakao_reader
   python reader.py --dry
   ```
   → `[김정헌] 처음 실행: …` 이 나오면 창을 찾은 것. (`--dry` 는 보내지 않고 개수만 봄)
8. 실행: `python reader.py` (창을 닫으면 멈춤). 한 번만: `python reader.py --once`
9. 켤 때 자동 시작: 작업 스케줄러 → 기본 작업 만들기 → '로그온할 때' → 프로그램 `pythonw.exe`, 인수 `reader.py`, 시작 위치 `C:\kakao_reader`.

## 견적발행시작 (사장님 10/30)
1. 김정헌 방에 올린다 (여러 번 나눠도 됨). 예:
   ```
   미래타운 3단지 견적 업체는 pk 디자인
   (사진 3장)
   사진 순서대로 1번 방문, 2번 화장실문, 3번 거실샤시 2중창 4m
   견적발행시작
   ```
2. **`견적발행시작`** 이 올라오기 전에는 노트북이 글을 모아 두기만 하고 **아무것도 하지 않는다** (사진 저장도 신호 뒤에).
3. 신호가 오면 그 앞 묶음(지난 신호·지난 링크 뒤의 글·사진)으로: 사진 저장 → 가견적 → 김정헌 방에 링크 → 텔레그램에 결과.
- 거래처: `견적발행시작 pk디자인` 처럼 신호 뒤에 쓰거나, 글 안에 거래처 이름이 하나 나오면 그 업체 ('업체는 pk 디자인').
- 사진 품목: 글에 '사진 순서대로 1번 방문, 2번 …' 이 있으면 그대로, 없으면 AI 가 사진을 보고 고름.
- 거래처를 못 찾으면(오타·비슷한 이름) 짐작하지 않고 현장관리 **'업체미확인'** 거래처로 넣는다 → 현장관리 앱 [+] 로 '업체미확인' 거래처를 꼭 만들어 두기. 텔레그램에 ⚠ 로 알림.
- 신호 없이 이름만 빼고 `견적발행시작` 만 써도 됨 (업체미확인으로 들어감).
- 묶음은 메모리에만 있어서 프로그램을 다시 켜면 비어 있다 → 그때는 글을 다시 올리고 신호.
- 텔레그램: n8n **카톡_알림** (`dnBRN9hF2GrCJZhZ`, POST `kakao-notify`, 사장님 열쇠, 원본 `n8n/kakao_notify/`) → 현장견적 봇, 챗ID 는 Airtable 가맹점 p_001. 사진을 끝내 못 저장했을 때·발행 실패도 알림.

## 새 글 알림 (chatlist.py, 사장님 10/30 A안)
- 확인할 때마다(1분) 카톡 메인 창을 그림으로 떠서 채팅 목록 오른쪽의 **빨간 숫자 배지**를 찾습니다. 방은 열지 않으므로 상대 카톡의 '1' 은 그대로입니다.
- 방 이름은 **윈도우에 들어 있는 한국어 글자 읽기(OCR)** 로 읽습니다 (인터넷·AI·돈 안 씀, `winocr.ps1`). 배지가 그대로면 OCR 도 하지 않습니다.
- 배지가 **새로 생기거나 숫자가 늘었을 때만** 텔레그램: `[카톡] 새 글` / `pk디자인 방에 새 글 3개`. 같은 알림을 반복하지 않습니다.
  숫자를 못 읽으면 "pk디자인 방에 새 글" 로만 알립니다 (배지 모양이 바뀌면 새 글로 봄).
- 처음 켤 때 이미 붙어 있던 배지는 기억만 하고 알리지 않습니다.
- **알릴 방** (사장님 10/30): `config.json` 의 `"watch_rooms": ["pk디자인", "한솔", "투나"]` 에 업체 방 이름(또는 그 일부)을 적습니다.
  적은 말이 방 이름 **안에 들어 있으면** 알립니다 (`"한솔"` → '한솔인테리어 김실장', '부평 한솔' 모두). 띄어쓰기·대소문자 무시, OCR 이 한 글자쯤 틀려도 됩니다.
  **여기에 없는 방은 알리지 않습니다** (새 고객 방도) — 새 업체가 생기면 여기에 더 적기. 비워 두면(`[]`) 모든 방을 알립니다.
- **빼는 방** (`watch_rooms` 를 비웠을 때 주로 씀): `"exclude_rooms": ["가족"]` — 적은 이름으로 **시작하는** 방은 뺍니다. `quote_rooms`(김정헌) 은 늘 빠집니다.
- 끄려면 `"watch_list": false`.
- 그림·OCR 결과는 노트북에 남기지 않습니다 (임시 폴더에 잠깐 썼다 지움). `state.json` 에는 방 이름·배지 숫자·배지 모양 지문만.
- **시험**: `python chatlist.py` → 지금 배지가 붙은 방 이름과 숫자를 화면에 보여 줍니다 (알림 안 보냄). 카톡 창 그림을 `chatlist_probe.png` 로 남기니 확인 뒤 지우고, 카톡으로 보내지 마세요.

## 견적 발행 (quote_bot.py)
- 새 견적 → 📋 요청 붙여넣기(카톡) → 초안 → 품목마다 사진 → 저장 → **가견적** 발행.
- 사진 품목은 n8n **견적사진_판단**(`photo-classify`, Gemini, 사장님 열쇠, id `NUXiFmg4mZxbxL4m`, 원본 `n8n/photo_classify/`)이 사진을 보고 고른다. 모르면 첫 품목에.
  빠진 정보(사는 집인지·다른 공정·필름·날짜)는 묻지 않고 견적서 메모에 적는다 (사장님 2026-10-29). 사진이 다 올라갈 때까지 기다린 뒤 링크.
- 시험: `python quote_bot.py --try "방문3개 부평 삼산동" 사진1.jpg … --client pk디자인`
- 고쳐서 다시 발행: `python quote_bot.py --revise 견적코드 샤시=2중창` (앞 견적은 '이전 견적' 으로 남음).
- 카톡 보내기(`kakao_window.send_text`): 창 제목이 방 이름과 같고 입력칸이 비어 있을 때만. 링크 글은 다시 견적 문의로 읽지 않는다.

## 화면에 나오는 말
| 말 | 뜻 |
|---|---|
| `채팅창이 열려 있지 않음` | 그 방 창을 카톡에서 열어 두기 |
| `새 글 2개 · 사진 1장` → `보냄 (200)` | n8n 이 받음 |
| `보내기 실패: HTTP Error 403` | `config.json` 의 열쇠가 틀림 (열쇠를 바꿨으면 여기도 바꾸기) |
| `보내기 실패: …` (그 밖) | 인터넷 문제 — 다음 확인 때 다시 보냄 |
| `[채팅 목록] 카톡 메인 창이 최소화…` | 카톡 메인 창을 열어 두기 (뒤에 있어도 됨) |
| `[채팅 목록] … '채팅' 탭이 아님` | 카톡 메인 창에서 말풍선(채팅) 탭 누르기 |
| `[채팅 목록] 윈도우 OCR 실패 (한국어 OCR 없음)` | 설정 → 시간 및 언어 → 언어 → 한국어 → 옵션 → '광학 문자 인식' 설치 |
| `[채팅 목록] pk디자인 +3` | 텔레그램으로 알림 보냄 |

## 사진 자동 저장 (기본 켬)
'견적발행시작' 신호가 오면 그 묶음의 사진 장수(`사진` / `사진 N장` 글)만큼 그 방 창을 앞으로 띄워 맨 아래 사진을 더블클릭 → 뷰어에서 Ctrl+S →
저장 창에 '카카오톡 받은 파일' 폴더를 넣어 저장 → ← 로 앞 사진도 저장 → Esc 로 뷰어를 닫습니다.
이미 저장된 사진이면 저장 창을 취소합니다. **마우스를 움직이므로 카톡 전용 노트북에서만** 쓰고, 방 창이 다른 창에 가리지 않게 두세요.
끄려면 `config.json` 에서 `"auto_save_photos": false` (그때는 사진을 손으로 받은 파일에 저장).
10/29 이 PC(화면 배율 150%)에서 김정헌 방 사진 2장 저장 확인.
